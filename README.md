## Car_Software 
Juan Sebastian Parra Pino
Desarrolla para facilitar la administracion de vehiculos. Permite registrar, consultar, actualizar y eliminar informacion relacionada con automoviles,como marca, modelo, año, color, placas y propietario. Su objetivo es optimizar la organizacion e los datos y agilizar la gestion vehicular mediante una interfaz sencilla y facil de usar
ESTRUCTURA DE PROYECTO: MVC
